# 📊 Contest Update Agent  

> Automated Weekly Competitive Programming Contest Reporting System  
> Built for Internal College CP Activity Tracking  

---

## 🚀 Overview  

Contest Update Agent is a lightweight automation tool designed to generate structured weekly Competitive Programming (CP) reports for college-level tracking.

The system fetches contest participation data, processes it, and generates a clean, shareable report format for internal reporting.

---

## 🎯 Purpose  

- Automate weekly contest reporting  
- Track student participation  
- Maintain structured and consistent updates  
- Reduce manual effort in report preparation  
- Provide a simple deployed web interface  

---

## 🛠️ Tech Stack  

- Python  
- Flask

- CSS  
- Netlify (Serverless Deployment)  
- Netlify Functions
